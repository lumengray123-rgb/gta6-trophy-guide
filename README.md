Leonida Trophy Atlas: an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI — every trophy with its official name, description and grade, a guide in our own words that cites its sources, a roadmap to the platinum, missable flags, and a checklist with saved progress, export/import, filters and a spoiler-safe mode. Fully offline, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
